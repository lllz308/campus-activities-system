# 验证方案

## 自动化验证

执行 `mvn test`，验证：

1. Spring 应用上下文可以创建。
2. 未登录用户可以查询已发布活动。
3. 学生能够登录并使用返回的令牌报名活动。

## 手工验收场景

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 教师发布 | 教师登录后创建 `PUBLISHED` 活动 | 返回活动 ID，公开列表可见 |
| 学生报名 | 学生登录后报名未满且未截止活动 | 创建报名记录，人数加 1 |
| 重复报名 | 同一学生再次报名同一活动 | HTTP 409，提示请勿重复报名 |
| 满员控制 | 报名人数达到容量后继续报名 | HTTP 409，提示名额已满 |
| 权限控制 | 学生访问教师管理接口 | HTTP 403 |
| 所有权控制 | 教师修改其他教师活动 | HTTP 403 |
| 删除保护 | 教师删除已有报名的活动 | HTTP 409，提示改为取消活动 |

## V1.0 结论标准

上述自动化测试全部通过，且手工验收的主流程与异常流程符合预期，即可认为当前实现达到本组定义的 V1.0 目标。
